One word describing my Wi-Fi: **Ghosted** — the phone clings to a dying network instead of switching.

The entry program (`main.ts`, Node, no dependencies) writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt`: `Ghosted` (6 characters, no trailing newline).
